# Actividad 1.4: Inicio del proyecto

Primer proyecto de Unity de la materia, creado con la plantilla "Universal 3D" (Universal Render Pipeline e Input System). Contiene un solo script, `Assets/Scripts/HolaMundo.cs`, que escribe "Hola mundo" en la consola del editor cuando inicia la escena.

El script está asignado al objeto `HolaMundoRunner` de la escena `Assets/Scenes/SampleScene.unity`. Para verlo funcionar: abre el proyecto con Unity 6000.5.9f1, abre esa escena con doble clic desde la ventana Project (la primera vez Unity abre una escena vacía sin título, no esta), abre la consola en Window > General > Console y presiona Play. Debe aparecer la línea "Hola mundo" sin errores ni advertencias.
